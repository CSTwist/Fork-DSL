# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2026-05-29
### Added
- Initial package foundation layout under `packages/com.fork.dsl`.
- Assembly definitions for `Runtime`, `Editor`, and `Tests`.
- Placeholder directories, namespace definitions, and NUnit smoke tests.
- Reference Unity project (`unity-project`) structure mapping to the package.
- Architectural Decision Records (ADRs) for simulation-presentation separation, data-driven runtime, and IR boundaries.
- Backlog milestone tracking and CLI test runner script.
